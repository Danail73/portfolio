# Портфолио — Данаил Маринов

Лично портфолио: кратка биография, технически умения и три проекта (JARVIS, Yu-Gi-Oh! Deck Builder, Green Care).

Статичен сайт — само `index.html` + папка `assets/` със снимки. Отваря се директно в браузър, няма нужда от сървър или build стъпка.

## Преглед

Отвори `index.html` локално, или виж го на живо през GitHub Pages (Settings → Pages → Deploy from branch → `main` / `/ (root)`).
